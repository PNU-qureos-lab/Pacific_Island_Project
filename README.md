# Pacific Island Project

This research project develops and validates methods for estimating
shallow-water depth and classifying benthic habitats around Pacific Island
countries using optical satellite imagery. It combines Sentinel-2 and
PlanetScope observations with drone orthomosaics and field-survey data.

The work covers satellite-data collection and preprocessing, atmospheric and
sun-glint correction, bathymetry modelling, habitat classification, accuracy
assessment, and validation. The project dashboard provides a central place to
follow its milestones, tasks, schedules, progress, and research outputs.
