# Pacific Island Project

Research project for developing shallow-water bathymetry estimation and
habitat-classification methods for Pacific Island countries using optical
satellite imagery.

## Live project dashboard

**[Open the Pacific Island Project dashboard](https://pnu-qureos-lab.github.io/Pacific_Island_Project/)**

The dashboard presents project milestones, detailed tasks, progress, schedules,
and related research documents. Progress updates made through the dashboard are
synchronized with Firebase.
